# Portfolio Arthur Novara

Portfolio personnel développé avec **Next.js 14**, **Tailwind CSS** et **Framer Motion**.

## Stack
- Next.js 14 (App Router)
- Tailwind CSS
- React 18

## Lancer en local

```bash
npm install
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000)

## Déployer sur Vercel

1. Pusher ce dossier sur GitHub
2. Connecter le repo sur [vercel.com](https://vercel.com)
3. Vercel détecte Next.js automatiquement → Deploy !
